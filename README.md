# webmanufaktur

Wir realisieren maßgeschneiderte Onlinelösungen — Internetauftritte für alle Anforderungen & Budgets.

Unser Markenzeichen ist [ProcessWire](https://processwire.com/), ein freies Open-Source-CMS auf PHP-Basis: eigene Module, Site-Profile und Snippets — einiges davon als Open Source hier im Account.

Dazu entwickeln wir Apps und Lösungen mit dem [BHVR-Stack](https://bhvr.dev/) (Bun, Hono, Vite, React) sowie Projekte mit [Astro](https://astro.build/).
